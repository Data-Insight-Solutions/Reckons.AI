# RDF (Resource Description Framework)

*Concept*

A W3C standard for representing knowledge as a graph of linked statements. The foundation of the Semantic Web. RDF itself is abstract -- Turtle, JSON-LD, and RDF/XML are concrete serialization formats.

## Steps

**[JSON-LD](../triples-rdf/jsonld)**

JSON-based serialization for RDF.

**[Linked Data](../triples-rdf/linked-data)**

Tim Berners-Lee's principles for publishing data on the web: use IRIs, use HTTP, provide useful RDF, and link to other datasets.

**[PROV-O (Provenance Ontology)](../triples-rdf/provo)**

A W3C vocabulary for expressing provenance: who created something, when, and from what sources.

**[RDF Schema (RDFS)](../triples-rdf/rdfs)**

A vocabulary for describing classes and properties: rdfs:Class, rdfs:subClassOf, rdfs:domain, rdfs:range, rdfs:label, rdfs:comment.

**[SKOS (Simple Knowledge Organization System)](../triples-rdf/skos)**

A vocabulary for taxonomies and concept hierarchies using skos:broader, skos:narrower, skos:related.

**[SPARQL](../triples-rdf/sparql)**

The query language for RDF graphs.
