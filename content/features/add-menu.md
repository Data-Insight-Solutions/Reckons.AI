# The add menu

The + button at the top of every page opens a short menu of what you can add. Under New: a source (a whole document), a single statement, a set or a new space. Under From: a note, a link, a folder, a code repository, a calendar, a reminder or a space file. Each choice opens the right page already set up for it. The arrow keys move through the menu and Escape closes it.
