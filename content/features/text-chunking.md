# Text Chunking

> **Scaffolded** — the structure exists, but it is incomplete. Expect gaps.

A long document is too big to read in one pass, so Reckons.AI reads it in overlapping pieces of about 12,000 characters. Each piece is labelled with the document title and its place (piece 3 of 8, for example), so nothing is read out of context. When two pieces produce the same fact, you see it once. This works for every kind of source.
