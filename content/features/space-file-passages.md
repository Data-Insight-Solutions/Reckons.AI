# A space file that carries its evidence

> **Functional** — built and working, with rough edges still being smoothed.

A space's file now holds the passages its facts came from, in their own section after the facts. Each fact's link to its words is written too, in the W3C Web Annotation form, so other tools can read it. Copy that one file to another computer or another person, import it, and Open in source still lands on the same words. Saving, sync, Google Drive backups, auto-save and export all write the passages; an import checks each passage against its fingerprint and never overwrites one that is already there. Files from before this change still import as they did.

<p class="derived">This is built and working.</p>

## Why it is this way

**Honest Note**

ORIGINALS STAY BESIDE THE FILE. The passages travel inside the space's file; the original documents they were cut from are still kept next to it, not inside the space's folder. Moving them is planned.
