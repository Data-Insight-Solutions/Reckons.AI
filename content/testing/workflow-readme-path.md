# Add a source, review it, see it in a space, ask for a reckoning

The path the README describes, start to finish: put a short note into Reckons.AI, settle the claims it proposes, find them in your space, and ask for a reckoning that works from what you settled. It is the whole point of the product in five steps, and a browser test runs it on every change.

## How these screenshots were made

**What they show.**

Every step is run on the **Getting started** sample that a first-time visitor opens, in which two people, Alex and Jordan, plan a camping weekend. Everything in it is invented, so the claims, counts and names in the pictures are sample content and not anyone's real notes.

**What is scripted.**

The test uses no language model. When it adds its own note in step 1, a stand-in reader returns placeholder claims, so the claims you see waiting in steps 2 and 3 are the ones Getting started already holds. In step 5 the reckoning is a fixed reply, written in advance to read like a real one. So the pictures show what each screen looks like and that it responds. They do not show how good a real model's claims or proposal would be, which is measured separately.

## The steps

### 1. Add a source

Open the Add tab, give the note a title, type or paste in a few sentences and press Extract facts. Reckons.AI reads the text and proposes claims from it. Nothing is accepted yet: every claim arrives waiting for your decision.

Where: the Add tab (`/ingest`).

**What the test checks.** The Extract facts button is enabled once a title and text are entered, and pressing it takes the person off the Add tab when reading finishes. The test's stand-in reader returns placeholder claims at this point.

### 2. Review the proposed claims

Open Review. Each claim waiting for a decision is a card. It names where the claim came from, shows the passage it was taken from, and offers accept, refine and reject. AI can misread what it reads, so this is where you check what it proposed against the original text.

Where: the Review tab (`/review`).

**What the test checks.** At least one claim is waiting on the Review tab, shown as a card with accept, refine and reject buttons.

### 3. Confirm the claims that are right

Press accept on each claim that matches its source. You can also refine a claim or reject it. Only claims you confirm become part of the space; anything left waiting stays out.

Where: the Review tab (`/review`).

### 4. See the claims in your space

Open Spaces. The claims you confirmed are now facts in your space, the collection of connected knowledge that everything you add feeds. The one you are working in is marked current, and its card says how many facts it holds.

### 5. Ask for a reckoning

Describe the situation you are in, say what you want to reach, and ask for a reckoning. It reads the facts in your space and proposes options and a recommendation, which you then weigh yourself. It is a proposal to evaluate, not an answer to trust.

Where: the Reckon tab (`/reckoning`).
