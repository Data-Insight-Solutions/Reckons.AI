*Concept*

The routes people actually take through Reckons.AI, each written as an intention rather than a feature. Start with the core loop below — every other path is that loop with one stage emphasised. They overlap deliberately, because the same person moves between them as their work changes.

## Details

**Principle**

- A PATH IS NAMED BY WHAT THE PERSON WANTS, NOT BY WHAT THE APP PROVIDES. 'Building a graph for research' is a path; 'Ingest' is a feature. If a path's name could appear in the settings menu, it has been named from the wrong side.
- THE UNIT IS A TRIPLE, AND THAT IS THE WHOLE DIFFERENCE. A notes app stores what you wrote. This stores what you MEANT, broken into separate claims small enough to disagree with one at a time — subject, relation, object. That is why the graph can tell you two sources conflict, that a claim rests on nothing, or that a question was never answered. A paragraph cannot do any of those things, however well it is written.

**Read First**

- IF YOU READ ONE THING, READ THE CORE LOOP. Everything here is the same four stages: something comes IN, the app PROPOSES what it thinks that means, you SETTLE what is true, and the settled graph is then USED — to decide, to compare, or to teach. A path is just that loop with the weight moved to a different stage.
