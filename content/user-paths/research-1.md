# Start a graph for the question, not for everything

*Concept*

Create a new graph per investigation rather than one graph for your whole life. Vocabulary repair and entity matching work by comparing new names against names the graph already holds, so a graph about one subject makes those matches meaningful and a graph about everything makes them noise.
