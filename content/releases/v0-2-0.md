# Reckons.AI v0.2.0

454 commits since v0.1.0, 157 of them features. This is the honest summary — what
shipped, and what is still not true.

## Highlights

- **Currents** — sources you subscribe to, arriving as translucent pod-view nodes for
  review rather than landing silently in the graph.
- **Archive** — sweep old facts into a dated archive graph, with a journal that can be
  rewound. An ingest that mentions an archived entity now offers to **restore** it instead
  of quietly minting a duplicate.
- **Graph publishing** — WebPage nodes round-trip to `content/*.md`, so this page and the
  rest of the docs are composed from the graph rather than written beside it.
- **A deterministic offline tier** — 19 checks that cost nothing to run: graph invariants,
  SHACL shapes, CSP origins, claim auditing, safety attestation. They run before every PR
  and are the reason several of the fixes below were found at all.
- **Multi-graph work** — cross-graph alignment, KB leaps, graph sets, and duplicate
  detection that can now compare copies rather than only reporting them.

## Fixes that matter more than they look

A theme ran through this release: **features that were green in tests and dead in a
browser**.

- **Repo ingest and site export had never worked from a browser.** `api.github.com` was
  missing from the Content-Security-Policy allowlist since the initial-release commit, so
  the browser refused the request before sending it. Both were marked shipped. Also fixed
  for Tavily, Firecrawl, and the default Reckons provider URL — and a script now checks
  every fetched origin against the policy, so this class cannot return quietly.
- **Self-hosted Indico could never be reached**, for the same reason plus missing CORS. The
  verifier was 6/6 green because it ran in Node, where neither is enforced.
- **The timeline placed undated nodes at their ingestion time**, so 93% of the starter
  graph sat in a wall at "today" and compressed the real events into a tenth of the axis.
  Undated nodes now get their own labelled lane.
- **Imported events were two hours wrong** — Indico renders times in the *category's*
  timezone, which the mapper discarded.

## Safety

The ethics preamble is no longer injected into every prompt. It is gated by **purpose and
locality**: anything **shared** always carries it, remote conversation carries it, and
local-only or structured-output paths do not — the latter because every written statement
already passes a deterministic content classifier regardless of what a model was told. The
ordering is now tested: a custom persona cannot precede the preamble, and a shared persona
served from a local model still carries it.

## What is still not true

- The review queue holds **736 proposals and none has ever been ruled on**. There is now a
  metric that says so.
- Estimates exist on five designs and only two have been scored; both came in under.
- SHACL validation **reports** and does not gate — nothing in the app is blocked by a shape
  yet, and users cannot author shapes for their own graphs.
- `staging` had drifted 84 commits behind `main`; this release reconciles the pipeline.
- **Seventeen** `js/file-system-race` findings are open, not the seven an earlier draft of this
  page claimed — that number came from a partial query and was wrong. Sixteen already existed on
  `main`; this release adds the same pattern in two new scripts. Every one is a
  check-then-act on a file (`if (!existsSync(p)) writeFileSync(p, …)`) in build and agent
  scripts — none of it ships in the app bundle. They are known, unfixed, and deliberately not
  bundled into this release; the fix is its own branch because it is mechanical and touches
  twelve files.
