# Reckons.AI v0.2.9

This is the **stories release**. Most of it makes a guided story easier to start, to pass on and to
trust: a story can now begin from a link, a step can be written into the page address, and narration
says so when your browser will not play sound.

Be clear about one thing first. This release was planned around **narrated demo videos on the
documentation pages. That is not done and is not in this release.** Two narrated demo renders
exist on the maintainer's own computer, but neither is on a documentation page. the maintainer chose on
2026-11-26 to release without them. Each item below says whether it is finished or partly done, and
what is missing.

## Stories

- **A personal showcase (partly done).** An example that is not in the list of examples and opens
  only from its link. Its story plays by itself, with no sound, and changes the filters and the
  layout from one step to the next. It holds off-the-clock facts only. Two of its planned
  phases, links onward to work examples, are not built, because each of those examples must be
  reviewed with the maintainer before it is public. So the showcase is not finished.
- **The Data Insight Solutions story, improved (finished).** It starts from its link without a click,
  gives each step its own filters and layout, shows the 3D ring, then the ring's contact sheet of
  frames, and ends with a jump into the ring's own example. It was checked in a browser on desktop
  and on a phone size. Reading it aloud with the real voice, and the 3D ring on a real phone, are
  still waiting for a person to check them.
- **A story step is part of the page address (partly done).** A step can carry its whole view
  in the address: layout, filters, selection and what is lit. One reader now handles links and
  stories. Several selected items travel in the address too. Not yet built: a check that every
  control has an address parameter, layouts that treat one selected item differently from a
  selected group, and a count of the selection on the screen.
- **Narration says when it is muted.** If your browser holds sound back until you click, the story
  now shows "tap to hear" instead of running on in silence.
- **Shelly opens on example links.** Opening an example by link opens Shelly on her help tab, with a
  short note that this is an alpha release. It is built and tested.
- **The phone story bar.** The step's links, play, the voice control and "tap to hear" sit in the
  bar and the bar has a solid background. A step's selection waits behind a "details" chip
  instead of covering the caption.

## Compare on the main picture (partly done)

- **Two sources, one named comparison.** From the Ingest page you can give two web
  pages or two files and get one named comparison, each fact keeping the source it came from. Built
  and tested with a stand-in reader; not yet tried against a real model by anyone but the builders.
- **A comparison layout.** The main picture can draw the two sources as overlapping circles: one
  color for what only the first says, one for what only the second says, and one for what both
  say, with counts. It opens from a link. Built and tested. The older Compare screen is still in
  place; the maintainer decided it goes once this works, and it has not been removed.

## Reckoning from chosen statements (partly done)

- **Start from what you select.** A reckoning can begin from statements you chose. The
  proposal is written back as items waiting for your review, and each option can be accepted or
  rejected, with a confirm step. Parts of the plan are still open, so this is marked in progress.

## Open a file from GitHub (finished)

- **A link to a .ttl file in a public repository opens as its own example.** It is built and tested
  in unit and browser tests. Not yet done: a link in the README, a read-only open, and fetching a
  newer version. GitHub allows 60 unauthenticated reads an hour per address, so a busy
  link can be refused.

## Checks

- **Human recheck (early).** A person's check is dated, and a script lists which checks are still
  open and which have gone stale because the code they looked at changed. It is built with unit
  tests. It is not yet run with the other checks and not yet shown on the release review page.

## Scans

- **Several recordings, one 3D picture (early).** On 2026-11-26 a combined 3D picture built from two
  separate recordings ran successfully on the maintainer's computer. That is his report: it is not
  recorded as a receipt in the project, the result was not measured against a single recording, and
  the recordings are private, so nothing about them is published here. It stays marked early.

## Not in this release

- **Narrated demo videos on the documentation pages.** Not done. This was the plan.
- **Three ways to play one story** (by hand, by itself, recorded). Planned, not built.
- **Hub assets, CAD parts and the job channel to the workspace folder.** In progress, and listed
  as partly done in the release's own roadmap entries.

## What to review

The release review example, `Review 0.2.9`, lists the main workflows with their screenshots so
you can mark each one pass or fail. It is not in the public list of examples.
