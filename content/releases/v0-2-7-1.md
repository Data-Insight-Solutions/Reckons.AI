# Reckons.AI v0.2.7.1

A small patch release with one purpose: making it possible for someone new to install and try **asset
generation on their own computer** (pictures, short video clips and 3D scenes made by open models,
with nothing sent to a cloud service) and to test it, whatever computer they have.

## What changed

- **One page for setup and testing.** [Generation tools and setup](/docs/features/generation-setup)
  now starts with a table of what each kind of computer can make, walks through five steps with the
  commands for macOS and for Linux, then gives a short test checklist, what to send back, what to do
  when something goes wrong, and how to remove everything afterwards (about 25 to 30 GB).
- **Macs with Apple Silicon (M1 or later).** The setup script now recognizes a Mac and installs the
  Mac builds of the picture-and-video tool and the room-scan tool. The app offers pictures and video
  on a Mac, and does not offer 3D scenes made from a single picture, because that model needs an
  NVIDIA graphics card. It says so instead of failing.
- **A fix the first Mac user would have hit.** The program that runs generation jobs on your computer
  used to wait for NVIDIA's monitoring tool before starting any job. A Mac never has that tool, so it
  would have waited forever. On a Mac it now starts the job.
- **Checked downloads.** The programs the setup script downloads are checked against fixed
  fingerprints before use. The model files are not checked yet.

## What is not true yet

**Nobody has run the Mac steps on a Mac.** They were prepared and checked on Linux, and the first
person to try them on a Mac is the real test. Expect rough edges, and please tell us what happens.
How much memory video needs on a Mac is an estimate, not a measurement; 16 GB is probably too little.
Intel Macs and Windows are not supported.
