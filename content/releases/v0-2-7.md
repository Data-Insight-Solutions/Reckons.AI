# Reckons.AI v0.2.7

This is the **agents release**. Reckons.AI is built with the help of AI agents: some run in the
cloud, and some run on the computer in front of you, on models you download once and own. This
release is about those agents. It gives you a place to watch them, makes their work quicker to
review, and lets them keep going when cloud usage runs out.

Be clear about one thing first: most of what is in here serves the people building Reckons.AI and
anyone who runs its agents themselves. If you use the app to keep your own knowledge, the change you
will notice is the new **This Device** page in Settings. Nothing about how you keep and review your
knowledge has changed.

## This Device

- **A new page in Settings.** Settings → This Device shows the computer you are on, the browser you
  are using, and what is installed: local AI models, connected tools, the browser extension and your
  app integrations. An integration shows as "configured", never "working", because the page cannot
  prove it works.
- **Watch the agents.** A Start button runs the agent watch from the page. A pinned row shows what
  matters at a glance (the queue, the local model server, what is running, failures in the last
  hour, the graphics card) and the detail folds away below it. It used to live only in a terminal
  window that kept scrolling away.
- **Where it works.** The watch reads the computer that runs the models, so it needs the
  development server on that computer. Opened anywhere else, the page still shows your browser and
  explains how to start the watch where the models are.

## Reviewing agent work is quicker

- **Links that land in the right place.** When an agent asks you to review its work, the link now
  opens the right space and the right batch, grouped by the run that produced it. If the app has
  lost permission to your folder, you get one Reconnect button instead of an empty page.
- **Questions are settled before they reach you.** When an agent has a question, it first looks
  for a decision you already recorded. It may answer only by quoting that decision word
  for word. A check refuses any quote that is not really there, and a second model has to agree the
  quote settles the question. Only what is still open comes to you.
- **A cleaner queue.** A check now finds damaged lines in the review queue, and agents that add to
  the queue take turns instead of writing over each other. On the day it ran, 15 damaged lines and
  110 duplicates were cleared out.

## A local stand-in when cloud usage runs out

- **The local deputy.** When the cloud model's usage runs out, a local model can carry on in the
  same coding tool, with the same rules. It cannot push code or merge anything, and it uses no
  cloud account. Everything it does is a proposal that the next cloud session reviews. It is
  slower and less capable than the cloud model, and it is told to say so rather than guess.
- **It remembers carefully.** What the stand-in learned in one session is kept aside for review, not
  merged into its memory automatically, and the next session is told it is waiting.
- **It can work on another project.** The stand-in and the Reckons.AI tools can now work inside a
  different repository, such as a website managed with Reckons.AI, and follow that project's own
  rules. The first person to run it in a new folder has to approve that folder once.
- **Measured, not assumed.** Before trusting a local model to check other agents' work, we gave it
  six cases with known answers, five times each. It got 26 of 30 right. Most of its misses were
  stopping to ask when it should have carried on, which is the safer kind of mistake, but it is
  still a mistake.

## Steps that cannot be skipped

Agents work fast, and fast work skips steps. This release starts moving the rules that matter from
written instructions into checks that run by themselves: a job must say how you will know it is
done before an agent can be handed it, and checks run when work is committed and pushed. This is
in progress. The brief check confirms the done-test is there, not that it is a good one, and most
rules are still written down.

## Moved to v0.2.8

v0.2.7 was first planned as the "reach" release: serving Reckons.AI from your own computer to your
other devices. None of that had started, so it moves to **v0.2.8**, together with the canvas and
analysis work that was moved here from v0.2.6. Moved because it was not started, not because it
was dropped.
