# Reckons.AI v0.2.5

The first release made the way 0.2.0 said releases should be made: one deliberate set of changes,
promoted from dev to staging to main together, with the version number, the build and this page
agreeing. Here is what changed, and what is still not true.

## Highlights

- **The Spaces map.** See all of your spaces at once and the links between them, drawn as a
  tide-pool tank. Other spaces load in the background, so the lines appear without a button.
  This is phase 1; the map as a mode of the shared canvas, and ghost spaces you know about but
  cannot open, move to 0.2.6.
- **The Source View, first half.** A source now keeps its text. Open a source and you see its
  passages and the statements each one produced. Select a node and you see which sources its
  facts came from, grouped by source, with a link straight to each. A statement shows the passage
  it came from as evidence. Long documents are split into recorded pieces, and a cut is never
  silent.
- **One graph canvas.** The review page's preview graph now uses the same canvas as the main
  view, so a fix to one is a fix to both.
- **The add menu.** The + button opens a short menu of what you can add, with a source at the top.
- **Sync to your phone.** Send a whole space to the phone's Files app. A sync service's conflict
  copy can no longer replace or duplicate a space.
- **Calmer labels.** A label is shown or hidden, never half-visible, and fades between the two.
- **Spoken commands.** Commands are recognized through a messy transcript, and the app refuses
  to guess when it cannot tell.
- **Plain words on screen.** The interface says space and graph, not "KB".

## Safety and correctness

- Template arguments are quoted for the shell, closing a real injection path.
- A node id written as a literal can no longer turn into a subject address and break an export.
- Every space has a stable id, and an import never adopts one already in use.
- The dependency audit is green again, including a deprecated release that had been pinned.
- Local machine checks keep their evidence private: only counts leave your machine.

## For developers: the local agent tier

Most of the repetitive work behind this release ran on local models and deterministic scripts
rather than a paid cloud model. [Thirty-six sentences](/docs/field-reports/thirty-six-sentences)
is a report on one session of it.

- **A local panel** hands many small judgments to local models and returns only the doubtful ones.
- **agent:watch** shows local model activity, the job queue, and a walking turtle; it now starts
  the queue worker itself.
- **A session-gated queue** runs local jobs only while you are working, never on an idle machine,
  and checks GPU heat and memory before each job. A circuit breaker stops a job that keeps failing
  the same way, and a failing schedule rests instead of looping.
- **Back-pressure.** A local job whose suggestions nobody has reviewed stops producing more until
  someone does.
- **Streamed local calls**, so a job waiting behind others no longer times out.
- **A merge queue** lands green pull requests on dev unattended, and **a docs gate** blocks a
  release while any shipped feature lacks a page.

## Not true yet

- **Big spaces are slow to draw.** Measured: at 10,000 statements the first 3D frame takes about
  12 seconds; at 100,000 the import takes about two and a half minutes. Rendering is the limit,
  not the file.
- **The Source View is half built.** Keeping folded source chunks inside a space's file needs
  importer support, which is planned for 0.2.6.
- **Currents moved back to scaffolded.** The client that fetches a current's items from n8n is
  written and tested, but nothing in the app calls it yet, so a current delivers nothing and the
  pod view has no arrivals to show. The roadmap no longer calls either one functional.
- **Untrusted-input hardening is partial.** See
  [Treating every input as untrusted](/docs/coding-workflow/untrusted-input).
