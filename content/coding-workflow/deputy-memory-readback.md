# What the deputy remembers, held back for review

> **Functional** — built and working, with rough edges still being smoothed.

Each deputy launch starts from a copy of the main session's project memory, so it works with the same remembered facts. What the deputy writes there is neither lost nor applied: at the next launch its own changes are held back as one patch in a folder of their own, and the next session that starts is told a patch is waiting, by name. Applying it is a deliberate act of a reviewing session — a deputy's memory writes are proposals, never merged on their own. They are kept out of the review queue on purpose: memory files are not facts awaiting review, and the queue already has a limit it is over.
