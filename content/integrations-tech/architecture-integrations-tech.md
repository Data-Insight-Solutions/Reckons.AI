# Technology Stack

*Concept*

Static SvelteKit 2 app with Svelte 5 runes. Threlte/Three.js for 3D, N3.js for RDF parsing, @huggingface/transformers for embeddings and local LLM, Dexie for IndexedDB storage. No server required.

## Steps

**[@huggingface/transformers v3](../integrations-tech/transformers-js)**

Runs ML models in the browser via ONNX Runtime WebAssembly.

**[Dexie.js + IndexedDB](../integrations-tech/dexie)**

Promise-based wrapper around IndexedDB.

**[Model Context Protocol](../integrations-tech/mcp)**

An open protocol by Anthropic for connecting AI models to external data sources.

**[N3.js](../integrations-tech/n3js)**

JavaScript library for parsing and writing RDF (Turtle, N-Triples, N-Quads, TriG).

**[Progressive Web App](../integrations-tech/pwa)**

Service worker (via @vite-pwa/sveltekit) enables offline access after first load.

**[shadcn-svelte](../integrations-tech/shadcn-svelte)**

Copy-in component foundation (button, badge, card, separator, skeleton) generated by the shadcn-svelte CLI and mapped onto the existing Liquid design tokens (--accent, --surface, --rad, etc.).

**[SvelteKit 2 + Svelte 5](../integrations-tech/svelte-kit)**

Web framework with adapter-static for fully client-side deployment.

**[Tailwind CSS v4](../integrations-tech/tailwind-css)**

Utility CSS engine, added as the foundation for shadcn-svelte components.

**[Threlte 8 + Three.js](../integrations-tech/threlte)**

Svelte bindings for Three.js.
